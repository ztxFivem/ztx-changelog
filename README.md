# ZTX Changelog

Änderungen der ZTX-Programme ohne eigenes GitHub-Repo. Jede Datei = ein Programm:

| Datei | Programm |
|---|---|
| `status.md` | ZTX Status |
| `screen-capture.md` | ZTX Screen Capture |
| `converter.md` | ZTX Converter |
| `server.md` | Server & Bots (Neuerungen auf dem Discord) |

Neuen Abschnitt `## <Version> – TT.MM.JJJJ` oben einfügen und speichern → der Eintrag erscheint automatisch im Discord-Kanal **#changelog**.
ZTX Bot Studio und ZTX Clips posten ihre Änderungen automatisch bei jeder neuen GitHub-Release.
